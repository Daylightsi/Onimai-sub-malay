# Onimai-sub-malay

**Onimai-sub-malay** is a project dedicated to providing or supporting the reading of manga in the Malay language. This repository may include translated manga files, reading scripts, or tools related to enjoying "Onimai" (and possibly other manga) in Malay.

## Features

- Manga content or scripts in Malay language
- Organized resources for readers and translators
- Open to community contributions

## Getting Started

1. Clone or download this repository.
2. Browse the available manga chapters or translation scripts in the provided folders.
3. Open the files with your preferred viewer or reader.

## Contributing

Contributions are welcome! If you want to help translate, proofread, or improve the resources:

1. Fork this repository
2. Create a new branch for your changes
3. Submit a pull request

Please make sure your contributions are in Malay and respect copyright guidelines.
